CSV Format / Example & Code Rules
The file must have exactly these two columns, in this order, with this exact header: 
vehicle_name,code

Forklift-01,XFL0001O
Forklift-01 (Sanitary),SFL0001O
Forklift-02,XFL0002O
8-character code structure:
PositionMeaningValid values
1stLocationX = Monica/Monalisa, S = Sanitary
2nd–3rdVehicle TypeAny 2 characters (e.g. PL, FL, DT, EF, EX)
4th–7thVehicle NumberExactly 4 digits (use last 4 digits if longer)
8thOwnershipO = Own, R = Rental

Driver Information

Add, search, edit, and remove drivers. Historical diesel records keep their own saved driver snapshot even after a driver is edited or deleted here.

Add New Driver
Bulk Import via CSV

Add many drivers at once from a CSV file.

CSV Format / Example
The file must have exactly these three columns, in this order, with this exact header: 
driver_name,driver_id,driver_mobile_number
Abdul Karim,DR-1025,017XXXXXXXX
Rahim Uddin,DR-1026,018XXXXXXXX
Kamal Hossain,DR-1027,019XXXXXXXX
No specific ID/mobile format is enforced — any value is accepted as long as it's not empty and not already used by another driver.

Consumption Rate

Set the average daily diesel consumption rate shown on each vehicle's "Last Consumption" card.

Set Consumption Rate
Bulk Import via CSV

Set rates for many vehicles at once from a CSV file.

CSV Format / Example
The file must have exactly these two columns, in this order, with this exact header: 
code,consumption_rate_per_day
DF01,12.5
DF02,10
The code must already exist in the vehicle list (created via "Create New QR Code"). Rows with an unknown code, a missing rate, or a non-numeric rate are marked invalid and skipped.

Dispenser Meter Reading

Correct/synchronize the recorded dispenser reading with the actual physical meter. Every diesel transaction continues to update this table via the existing dispenser-meter logic — this only lets you set the record straight for a given date.

If a record already exists for this date, it will be updated with this corrected value. Records for every other date are left untouched.
